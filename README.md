# Customer Shopping Behavior Analysis

## Project Overview
This project analyzes customer shopping behavior using Python, SQL, and Power BI. The goal is to explore purchasing patterns, customer preferences, subscription behavior, discounts, and revenue trends.

## Tools Used
- **Python (Google Colab):** Data cleaning and exploratory data analysis.
- **MySQL Workbench:** SQL queries to answer business questions and analyze customer purchasing behavior.
- **Power BI Desktop:** Interactive dashboard for visualizing key findings.

## Project Files
- `customer_shopping_analysis.ipynb` — Python notebook containing data cleaning and exploratory analysis.
- `customer_shopping_analysis.sql` — SQL queries used to investigate business questions.
- `customer_behavior_dashboard.pbix` — Power BI dashboard presenting the analysis.
- `customer_shopping_cleaned.csv` — Cleaned dataset used in the analysis.

## Key Analysis Areas
- Revenue and purchasing behavior by gender and age group.
- Product ratings and purchasing patterns.
- Customer subscription status and spending.
- Discount usage and product-level discount rates.
- Shipping methods and purchase amounts.
- Customer segmentation based on previous purchases.

## Dataset
The project uses customer shopping data containing 3,900 records. The dataset includes customer demographics, purchased items, purchase amounts, review ratings, subscription status, discounts, and shipping information.

## Key Findings
The analysis found total purchase revenue of **233,081** across 3,900 records. Male customers contributed 157,890 in revenue, while female customers contributed 75,191. Non-subscribers contributed more total revenue than subscribers, though the dataset also contains substantially more non-subscribers.

## How to Explore the Project
1. Open the Python notebook to review the data preparation and exploration.
2. Review the SQL file to see the business questions and queries.
3. Open the Power BI `.pbix` file in Power BI Desktop to explore the dashboard.
